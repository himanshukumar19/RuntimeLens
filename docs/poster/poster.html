Why Existing Approaches Are Insufficient
Static Scans Miss Runtime
Vulnerability scanners (e.g. Trivy) only inspect build artifacts. Clean images can still spawn malicious reverse shells or hijack compute post-deployment.
Blind to Orchestration
Host-level eBPF misses Kubernetes control-plane semantics: RBAC role bindings, cross-namespace Secret queries, and pod lifecycle modifications.
Lack of Workload Context
An interactive shell or network connect is routine for debugging tooling, but catastrophic for an automated payment workload. Global rules trigger massive false-positive noise.
Opaque Uncalibrated Models
Standard LLMs produce uncalibrated probabilities, suffer hallucinated rationales, and invite prompt-injection attacks from attacker-controlled process strings.
Primary Research Claim
Adding declarative, Git-versioned workload baselines to runtime and orchestration telemetry improves macro-F1 and reduces benign false-positive rates compared to the same classifier without baseline context, evaluated via paired counterfactual comparisons without synthetic telemetry shortcuts.

Steps 2 & 3
Event Normalization, Workload Baselines & Pre-Filtering

Events are normalized to CanonicalEvent v1.0.0 and matched against Git-versioned profiles in baselines/*.yaml with a ±30s temporal correlation window. Deterministic pre-filtering removes routine operations (e.g. readiness probes) to minimize model invocations.

Step 4: Classification via ScaleDown Classify-1 Decisions API
Single forward-pass evaluation over XML-escaped structured state
ScaleDown Classify-1
Choice Question: attack_type
Evaluates 5 mutually exclusive classes: benign, container_escape, privilege_abuse, cryptomining, unknown.
Returns discrete label, class probabilities, and top-class confidence.
Score Question: severity
Scores criteria levels 0 to 4 (Informational to Critical).
Computes continuous expected score: Σ i · P(i).
Continuous Severity = Score + 1.0 ∈ [1.0, 5.0].
Noul Questions: Evidence Flags
4 independent scalar flags ∈ [0.0, 1.0]:
• baseline_deviation (unauthorized binary/path)
• shell_unexpected (interactive shell)
• resource_exposure (host socket/path)
• resource_abuse (abnormal compute/egress)
Measured Model Latency: 0.90–1.16 s (median 1.04 s)
Cluster Corpus: 84 Verified Runs (100% of 55 Templates, Macro-F1 0.5603)
Adversarial ASR: 0.0% (under full defense tier)
Step 5
Pure Deterministic Policy Engine Confidence Gate: ≥ 0.70

Combines model predictions with deterministic conflict resolution matrix. Degraded telemetry forces fallback to alert-only with human review. Low confidence (< 0.70) routes directly to analyst investigation queue.
